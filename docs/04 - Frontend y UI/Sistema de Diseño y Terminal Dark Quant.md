# 🎨 Sistema de Diseño y Terminal Dark Quant

## Filosofía Visual
Inspirado en la interfaz de terminales financieras profesionales (Google Stitch Design):
* **Fondo Principal**: `#051424` (azul marino muy oscuro / terminal moderna).
* **Superficies y Tarjetas**: `#111827` y `#122131`.
* **Acentos Primarios**: `#4edea3` (verde esmeralda cuant) y `#38BDF8` (azul cielo tecnológico).
* **Tipografía**: Fuentes monoespaciadas (`font-mono`) para números, precios, porcentajes y tickers; sans-serif legible para títulos y tesis.

## Componentes Principales
1. **Ticker Tape Superior Fijo**: Muestra cotizaciones y variaciones diarias de S&P 500, Nasdaq 100, Merval, Dólar CCL, Bono USA 10Y y VIX.
2. **Hero con Métricas Clave**: Resumen en tiempo real del tipo de cambio y contexto macro.
3. **Pestañas y Sub-pestañas**: Segmentación fluida entre Acciones CEDEAR, ETFs, ONs en Dólares y Mercado Local.
4. **Tarjetas de Activos en 12 Columnas**: Disposición tipo Bloomberg Terminal con jerarquía visual clara.
5. **Simulador de Cartera**: Selector interactivo de capital (ARS/USD) y perfil de riesgo.
